# AI 配置 / 记忆 / 预设库 / 四页 UI 优化设计

## 1. 背景与已确认决策

当前插件已有 4 个核心页面：

- `AI 助手`
- `偏好设置`
- `运行记录`
- `AI 配置`

已确认需求与决策：

1. 多模型渠道记忆：**按 `渠道 + 模型` 完全隔离**
2. 提示词预设库：**全局库 + 个人覆盖**
3. 页面布局风格：**两栏仪表板**
4. 技术路线：**方案 A（渐进增强，兼容现有接口）**

---

## 2. 目标与非目标

### 2.1 目标

1. 让不同模型间的会话记忆彻底隔离，避免串话
2. 提供可复用的提示词预设库（内置模板 + 用户覆盖）
3. 优化四页信息布局，提高高频操作效率与可读性
4. 兼容当前接口与存量配置，支持平滑迁移

### 2.2 非目标

1. 不重构后端为“独立记忆中心服务”
2. 不替换现有主流程 API（如 `/api/job/seeker/cloned/ask`）
3. 不引入新页面，仅在现有 4 页内重排与增强

---

## 3. 设计总览（方案 A）

### 3.1 核心抽象

新增统一主键：

- `ModelChannelKey = "{provider}:{modelName}"`

所有记忆与预设配置均以 `ModelChannelKey` 为一级命名空间。

### 3.2 配置分层

新增配置扩展块（前端优先，后端可选持久）：

- `ext.memoryProfiles`
- `ext.promptPresetStore`
- `ext.uiLayout`

主配置（已有字段）继续沿用：

- `provider`, `modelName`, `apiKey`, `baseUrl`, `timeout`, `status`, `userPrompt` 等

---

## 4. 多模型记忆存储与使用

### 4.1 现状问题

当前 AI 坐席会话键以 `jobKey` 为核心（如 `encryptJobId:uid`），模型切换时存在跨模型上下文污染风险。

### 4.2 新方案

将会话键升级为：

- `SessionKey = "{jobKey}@{ModelChannelKey}"`

效果：

1. 同一岗位在不同模型下会话分离
2. 同一模型下会话连续
3. 迁移成本低（只扩展 key 生成规则）

### 4.3 记忆策略配置（每个 ModelChannelKey 独立）

`MemoryProfile` 结构：

```json
{
  "enabled": true,
  "scope": "session",
  "maxTurns": 20,
  "summaryThreshold": 12,
  "clearOnModelSwitch": true
}
```

说明：

- `scope`: `session | job | global`（默认 `session`）
- `maxTurns`: 上下文携带轮数上限
- `summaryThreshold`: 达到阈值后触发摘要压缩（前端标记 + 后端兼容）

## 5. 提示词预设库（全局库 + 个人覆盖）

### 5.1 数据结构

`PromptPreset`：

```json
{
  "id": "preset-uuid",
  "name": "稳健沟通-技术岗",
  "tags": ["通用", "技术"],
  "content": "...prompt...",
  "scope": "global|personal",
  "provider": 1,
  "modelName": "deepseek-chat",
  "enabled": true,
  "updatedAt": 0
}
```

### 5.2 组装顺序（固定）

运行时最终提示词：

1. 全局内置模板（只读）
2. 渠道级模板（provider）
3. 模型级模板（provider + modelName）
4. 用户输入附加（`userPrompt`）

并在 UI 显示“最终拼装预览”，便于调试。

### 5.3 覆盖规则

- 同名预设优先取 `personal`
- 删除 personal 后自动回退 global
- 支持一键“恢复内置模板”

## 6. 四页 UI 重排（两栏仪表板）

### 6.1 公共布局规范

- 顶部：状态条（当前模型、记忆状态、预设状态、保存状态）
- 左栏（40%）：配置与控制
- 右栏（60%）：预览、日志、结果
- 小屏断点：`<1280` 自动堆叠为单栏

### 6.2 AI 助手页

左栏：

- 批量投递/收藏主控
- AI 坐席开关、导入简历、关键开关

右栏：

- 实时记录（可筛选：投递/收藏/AI）
- 成功失败统计卡片

### 6.3 偏好设置页

左栏：

- 账号与通知配置
- 过滤开关（公司/薪资/活跃度等）

右栏：

- 策略预览（当前筛选快照）
- 导入导出与“变更 diff”提示

### 6.4 运行记录页

左栏：

- 过滤器（时间、级别、关键词）

右栏：

- 日志表 + 分页
- 常用操作（清空/导出）固定在工具栏

### 6.5 AI 配置页（重点）

左栏：

- 提供商 / 模型 / API 配置
- 记忆策略配置（按 `ModelChannelKey`）

右栏：

- 预设库管理（全局 + 个人）
- 最终提示词预览
- 调试会话窗口（保留）

---

## 7. 兼容与迁移

### 7.1 向后兼容

- 若 `ext` 缺失：按默认策略初始化，不影响现有流程
- 原 `userPrompt` 继续有效
- 原 provider/model 配置不改接口

### 7.2 迁移策略

首次加载执行：

1. 生成默认 `ModelChannelKey`
2. 初始化默认 `MemoryProfile`
3. 注入内置 `globalPresetCatalog`
4. 将现有 `userPrompt` 挂到当前模型 personal preset（可选）

---

## 8. 错误处理与可观测性

1. 预设拼装失败：降级仅使用 `userPrompt`
2. 记忆读写失败：降级为“无记忆模式”，给出告警但不中断投递
3. 模型切换时会话 key 异常：回退旧 key 并记录 warn
4. 新增日志标签：`[AI配置] [记忆] [预设] [UI布局]`

---

## 9. 验证计划

### 9.1 功能验证

1. 同岗位切换模型后上下文不串

### 9.2 回归验证

2. AI 坐席回复与日志功能可用
3. 偏好设置导入导出可用
