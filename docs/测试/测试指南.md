## 已知问题

### 构建大小增加
- **现象**: 构建文件从 3.8MB 增加到 3.99MB (+5%)
- **原因**: 新增 BossApiClient 和工具模块
- **影响**: 可接受，gzip 后仅增加 2KB
- **优化**: 后续可考虑代码分割

### UNC 路径限制
- **现象**: 无法在 UNC 路径下运行 npm 命令
- **解决**: 使用映射驱动器 (Z:)
- **影响**: 仅影响开发环境，不影响用户
