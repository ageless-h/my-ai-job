# UI美术回归清单 v1

> 目标：确保右侧竖向插件在长期高频使用下，保持审美一致、层级清晰、交互稳定。

## 1. 回归范围

- 面板结构：顶部高、左侧窄（header + nav 组合）
- 六个 Tab：
  - 工作台（AiJob）
  - AI能力（AiConfig）
  - 投递过滤（DeliveryFilter）
  - 消息管理（MemorySession）
  - 运行日志（RunRecord）
  - 账户数据（Account）

## 2. 测试环境约束

- 使用唯一端口进行可视化回归（避免多端口并行占用）
- 同一轮回归使用同一浏览器缩放比例与系统主题
- 截图命名采用：`ui-tab-<tab>-<width>.png`

## 3. 宽度档位矩阵

- 窄档：`~360px`
- 中档：`~420px`
- 宽档：`~480px`

每个 Tab 在 3 个档位都需要截图 + 人工审美检查。

## 4. 全局视觉验收项

### 4.1 圆角与边框

- 所有按钮（含 Element Plus 按钮）使用统一小圆角
- 主要卡片圆角一致，无“盒中盒”边框噪音
- 分割线弱化，不抢占主信息

### 4.2 层级与强调

- 主标题、区块标题、正文、辅助说明层级清晰
- 主色只用于关键动作和关键状态，不泛滥
- 危险动作（如清空）视觉权重低于主流程动作

### 4.3 排版与密度

- 窄栏场景无拥挤、无明显空洞
- 行间距和段间距在 6 个 Tab 保持一致节奏
- 关键数据（数字、状态）可在 1 秒内识别

### 4.4 交互稳定性

- 时间范围控件宽度固定，不随侧栏拖拽变化
- 表格/分页关系稳定，不出现跳动或大面积空白
- 按钮 hover/active 状态一致且不过度动画

## 5. 分 Tab 验收要点

## 5.1 工作台

- 统计卡信息密度合理，数字视觉焦点明确
- 操作区不出现横向拥挤与按钮错位

## 5.2 AI能力

- 标题层级与字号统一（16px 层级）
- 配置卡片内外边距一致，操作按钮权重清晰

## 5.3 投递过滤

- 表单区块节奏稳定，控件对齐自然
- 保存/恢复等操作区主次分明

## 5.4 消息管理

- 说明文本可读性达标（低对比问题已消除）
- 策略编辑区无挤压，无无效空白

## 5.5 运行日志

- 时间控件尺寸固定
- 清空按钮为软危险样式，不压过主流程按钮
- 表格主体与分页贴合，阅读路径顺畅

## 5.6 账户数据

- 窄栏下信息区域布局稳定（关键字段单列展示）
- 操作按钮不换行错位，视觉节奏统一
